₿ BTC 멀티 타임프레임

백테스트 ↗ 불러오는 중…
📘 사용법 — 위에서 아래로 3단계
1
방향 확인 — 매트릭스

일목 열에서 1시간·4시간·일봉이 모두 같은 쪽이면 방향이 있는 것입니다. 섞여 있으면 진입하지 않습니다.

우상단 종합 %가 +25% 이상이면 상승 우위, −25% 이하면 하락 우위입니다.

⚠ 1분·15분은 방향 판단에 쓰지 마십시오. 백테스트에서 15분봉은 모든 규칙이 비용 차감 후 마이너스였습니다.

2
레벨 확인 — 타임프레임 카드

방향을 정한 타임프레임 카드에서 손절 자리를 봅니다. 롱이면 「손절 · 롱」, 숏이면 「손절 · 숏」 값입니다.

ATR×1.5 거리라 일상적인 흔들림에는 걸리지 않습니다.

R은 손절까지의 거리입니다. 1R 도달 = 잃을 뻔한 만큼 벌었다는 뜻입니다.

3
크기 결정 — 계산기

아래 순서로 5번만 누르면 됩니다.

  1. 증거금에 실제 넣을 금액 입력
  2. 방향 선택 (롱/숏)
  3. 현재가 버튼 클릭
  4. ATR 버튼 클릭 → 손절가 자동 입력
  5. 레버리지를 줄여가며 체크리스트가 8/8이 되는 값을 찾기

5번이 핵심입니다. 8/8이 되는 레버리지가 지금 변동성에서 이 손절을 감당할 수 있는 상한입니다.

🔴 빨간색이 뜨는 조건
청산까지 5% 미만하루 변동폭 안에 청산가가 들어옴
손실이 증거금 30% 초과한 번 손절에 3분의 1이 사라짐
ATR 대비 1배 미만손절이 너무 좁아 노이즈에 털림
체크리스트 3개 이상 실패박스 전체가 붉어짐

청산가·손실액은 조건과 무관하게 항상 빨갛습니다. 잃는 쪽 숫자라 색으로 구분한 것입니다.

📐 예시 — 증거금 720, 4시간 롱
20x청산까지 4.6% · 6/8 · 빨강
10x청산까지 9.6% · 8/8 · 초록

→ 720 증거금에 10배가 상한. 그보다 높이면 방향이 맞아도 중간에 잘릴 확률이 올라갑니다.

이 도구는 「들어가라」고 말하지 않습니다. 방향은 1단계에서 직접 판단하시고, 계산기는 그 판단이 틀렸을 때 얼마나 잃을지를 미리 보여줄 뿐입니다.
